# TaskTrack: Assignment and Deadline Tracker

## About the Project

TaskTrack is a simple program that helps students keep track of their assignments and deadlines.

The program will allow users to add assignments, view their assignments, and mark tasks as completed. It is meant to help students stay organized and avoid forgetting their schoolwork.

## Planned Features

* Add assignments
* Add deadlines
* View assignments
* Mark assignments as completed
* Show unfinished assignments

## Project Status

This project is currently in the planning stage. The project proposal and basic project structure are being prepared before the actual program is created.
